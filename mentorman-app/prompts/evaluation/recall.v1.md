# Evaluation — Recall Question Guidelines v1
# Used by EvaluationService for Q1–Q2 (recall level questions)

Ask the user to state, define, or describe a core concept from {{eval_topic}}.

Good recall questions:
- "Walk me through how X works."
- "What's the difference between X and Y?"
- "What does X guarantee, and what doesn't it?"

Bad recall questions (avoid):
- "What is the definition of X?" — too textbook, not engineering-relevant
- "Name 3 uses of X" — list-making, not understanding

The question should take 2–3 sentences to answer well. If it can be answered in one word, it's too shallow.
